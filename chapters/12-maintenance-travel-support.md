# 12 · 维护、旅行特殊场景与支持

> 覆盖设置备份/导出导入、版本升级注意事项、历史数据清理、时区/夏令时旅行、运动/饮酒/疾病/儿童场景，以及获取帮助与贡献文档。

## 12.1 备份与导出/导入

### 必须备份
- **APK 副本**：同 keystore 签名才能无感更新；存电脑 + 云盘专用文件夹。
- **设置导出文件**：加密（需主密码）；**每次完成目标、重大更改（SMB/胰岛素类型/换泵/自动化）、换 Pod 后、每月至少一次**导出。多留几份旧文件。
- 忘记主密码 = 无法导入加密设置！

### 自动化导出
- 偏好 > 维护 启用"无人值守设置导出"；可由自动化每周或换 Pod 后导出。
- 启用后主密码本地存≤4 周，到期通知，1 周宽限期后失效须重输。

### 导入
- 总需输入 AAPS 密码。
- 同 keystore 更新 APK 无需此流程（但仍建议先备份）。

## 12.2 版本升级注意

- 检查该版"特别注意事项"（发布说明）。
- **数据不迁移**（尤其大版本如 3.0）：升级后 IOB/COB/治疗清零，需重建 Profile 切换——**在无活性胰岛素和碳水时升级**。
- NSClient v3 vs v1：WebSocket 持久连接更费电；目前 NS 内部仍 v1，用 v3 时不能经 NS 网页手输数据（远程输入须 SMS/AAPSClient）。**全设备统一 v1 或统一 v3**。
- 强烈建议仅 AAPS 统一收集上传，其他只读——避免冲突。
- 升级后主屏附加图表可能丢失，手动记录恢复。
- 检查自动化规则：新版可能加限制（如原 140% 超限改 130%），红色标记规则含无效操作须编辑。

## 12.3 历史数据清理（Reviewing）

- AAPS 自有数据库无法导出/复制，可定期清理旧数据（上传 NS 后回顾）。
- 数值多参考 ADA 2023 建议；与内分泌科医生讨论目标。

## 12.4 旅行：时区与夏令时（Cross-timezone / DST）

- 手机设"自动日期和时间"，但若 Android 单一开关同时控时间与时区，须关闭自动时区以便手动改。
- 多数泵驱动自动把泵时间对齐手机时间（Combo 新驱动、Insight、Medtrum、DASH、Eros 等）；旧 Ruffy Combo 驱动须手动。
- Insight 内部小电池换电过长会重置时钟→AAPS 跳过此前记录（须重输时间日期）。
- **安全做法**：
  - 改时区前：勿按"删除未来的治疗"；若 IOB/COB 不清，至少禁用闭环一个 DIA 与 Max-Carb-Time 之较长者。
  - 改完：把 Android 时区改回当前位置、重启用自动时区。
  - 向西旅行 Medtronic 已知问题，谨慎监测（见 GitHub issue）。
- Libre 2 跨时区有专门注意（见文档更新）。

## 12.5 运动（Exercise）

- 闭环会识别并校正你为运动摄入的碳水。
- 建议：设 **Activity TT**（高于标准目标）+ 若用 SMB 则禁用"高 TT 时启用 SMB"与"始终 SMB"。
- 规律运动可考虑自动化切 Profile/TT；基于位置自动化增加预处理难度。
- 百分比/Activity TT/调整时间因人而异——从安全范围起步（低百分比 + 高 TT）。
- 锻炼前减 IOB（泵或 HCL 模式）。

## 12.6 饮酒（Alcohol）

- 闭环难预测酒精影响，**有风险**。
- 选项：停闭环手动控糖；或设高 TT + 禁用 UAM（防未记录餐食增 IOB）。
- 必须持续盯 CGM，靠摄入碳水手动防低。

## 12.7 疾病（Sickness）

- 胰岛素抵抗升→高血；可设自动化（如 BG>8 mmol/l 切 120% Profile，限时长/特定日/时段/位置）。
- 无放之四海皆准的自动化规则，须自定。

## 12.8 儿童（见 `chapters/06` 6.10）

- 调 BR/DIA/ISF/IC 更难（生长激素）；周末/假期测试。
- 保护：密码/生物识别锁大剂量、设置更改、AAPS 本身。

## 12.9 获取帮助（层级）

1. **第一层**：先查 AAPS 文档（按关键词搜）。
2. **第二层**：Facebook AndroidAPS 群组 / Discord（含 Combo 专项 AAPSCombo）。
   - 注意 Facebook 近期移除群内外部链接（含历史帖），用文档关键词搜。
   - 跨平台转载会被忽略/删；多数开发者在欧洲，非全天即时回，周末/节假日可能数小时。
3. **第三层**：Facebook 未解决→Discord 提问。

## 12.10 贡献与文档

- **翻译**：Crowdin 注册选语言等授权；应用字符串或文档 Markdown。
- **文档编辑**：GitHub "Edit on GitHub"（仅英文页）；Markdown + myst_parser；注意唯一命名锚点、避免长表、隐私不泄密（API key/密码）。
- **代码**：Issues + Discord 协作，从简单任务起首 PR。
- **Open Humans**：可选捐数据助科研，随时停/删。

## 12.11 常见排障速查（详见 `cheatsheet.md`）

- 红色三角（重复 BG）→ 删 NS 重复条目；黄色三角（间隔不稳）→ 多因 Libre/换 G6 发射器，闭环仍运行。
- 运行开发版报"闭环已禁用"→ 需 engineering_mode 处理（重命名日志为 `engineering_mode` 无扩展名）。
- 与 RL 断连 → 检查手机电池优化/蓝牙；泵不可达阈值设 120min。
