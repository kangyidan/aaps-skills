# 03 · 构建、安装与手机配置

> AAPS 没有 Google Play 版本，必须自行构建 APK。本章覆盖构建前置、安装传输、以及华为/Jelly 等机型的省电与后台保活配置。

## 3.1 为什么必须自己构建

- 法律要求：AAPS 是未获许可的软件，不能分发预编译 APK。
- 更新时须用**同一密钥库（keystore）**签名，才能无感保留设置与数据库。密钥库务必安全备份（电脑 + 云盘专用文件夹）。
- 构建方式：Android Studio 编译；详细步骤见官方文档，核心要点如下。

## 3.2 构建环境要点

- Git（注意 `git --version` 的空格与双连字符）。
- Gradle：建议 8.9；最大兼容 Gradle JVM 为 19（示例 JBR-21 可选）。
- 若构建报"按需配置（configure on demand）"错误，需关闭该选项。
- 构建成功但显示黄色/蓝色编译器警告可忽略；输出 APK 在输出目录。
- 若更新时复用同一 keystore，无需卸载旧版；否则需先卸载重装并重配。

## 3.3 安装与传输

- 通过数据线把 APK 拖到手机"下载"文件夹，长按 APK → 安装。
- **不建议用电子邮件传输**（易出错）。
- 构建 Wear OS 版时，建议**同时用同一 keystore 构建手机与手表 APK**，以确保成功配对。

## 3.4 手机系统配置（关键：保活 AAPS）

AAPS 需每几分钟收血糖读数、跑算法、下指令，故 Android 必须允许其后台运行：

- **关闭自动电池优化 / 加入白名单**：防止系统杀掉 AAPS 或蓝牙（会导致与泵/RL 断连）。
- **保持屏幕常亮**（首选项）仅用于演示，日常需连充电线，否则耗电。
- 设置"保持运行"类选项，参考各机型文档。

## 3.5 华为手机（Huawei）

- 移除"自动管理"，改为手动允许自启动、关联启动、后台运行。
- 对 xDrip+ 须启用持久通知（应用内）。
- 不同机型选项名称有差异，按实际界面调整。

## 3.6 Jelly（小屏手机）

- 仅推荐有经验的闭环用户（按钮小、需细腻触控）。
- 厂商"优化功能"会干扰 AAPS，须为 AAPS 及 BYODA/xDrip+/OOP2/Juggluco 等 DIY 应用**禁用优化**。
- 可启用智能辅助，但须为 DIY 应用禁用它。

## 3.7 安装后第一步

- 安装后进入**设置向导（Setup Wizard）**，逐项配置权限、泵、CGM、Profile——见 `chapters/04`。
- 设置向导结束即进入**目标 1**，功能随目标解锁。
- 若误退向导，可重启向导或手动改配置。

## 3.8 安全提醒

- 主密码用于加密导出设置——**务必记好并备份（如 Google Drive）**，丢失将无法恢复 Profile 与目标进度。
- 看护场景：被看护手机须启用"使用手机流量"，否则 WiFi 范围外无法上传数据。
