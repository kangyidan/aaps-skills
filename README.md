# aaps-skills

AndroidAPS（AAPS）开源人工胰腺 / 混合闭环系统的**结构化学习笔记与运维参考技能**（WorkBuddy / CodeBuddy skill）。

本仓库由 AAPS 官方中文文档（<https://androidaps.readthedocs.io/zh-cn/latest/>）经 book-to-skill 流程提炼而成，作为可调用技能使用。

## 内容

- `SKILL.md` — 入口：心智模型、原则、章节导航、使用方式
- `chapters/01`~`12` — 12 个主题学习笔记
  - 概念心智模型 / 硬件组件 / 构建安装 / 设置配置·Profile / 目标系统 / 日常使用 / 闭环算法 / Autotune+自动化 / 远程功能 / 兼容泵 / CGM+WearOS / 维护·旅行·支持
- `glossary.md` — 术语表（AAPS / SMB / UAM / TBR / DynISF / ISF / IC / COB / IOB / maxIOB / Autosens …）
- `patterns.md` — 模式与反模式
- `cheatsheet.md` — 速查表（泵/CGM 兼容矩阵、SMS 命令、目标时间表、故障排查清单、安全红线）

## 重要声明

本仓库为**技术学习笔记**，仅提炼结构、原理与参数定义，**不复制原文段落**，不替代专业医疗建议。AAPS 是未获监管机构批准的 DIY 医疗实验，所有胰岛素治疗决策须与糖尿病医疗团队共同制定，使用后果由使用者自行承担。
